# Nairobi Blaze Academy App

This folder contains the Next.js frontend for the Nairobi Blaze Academy project.

## Purpose

The app is intended to serve as a modern frontend for the academy brand and to complement the main Express-based site in the repository root. It provides a polished interface for showcasing Nairobi Blaze Academy, its values, and its player-development journey.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Notes

- The root project is the main deployment entry for the academy website and registration backend.
- This sub-application is best used for frontend development and UI experiments.
- For the backend and registration APIs, use the Express server in the repository root.
